## How it is wired

The site stays static. The page ships one small client script that streams tokens from a model I
finetuned, served on a free Hugging Face Space. No server, no adapter, no framework.

```
browser ---- fetch + SSE ----> granolacowboy-gc-guide.hf.space   (finetuned model, streaming API)
   |                                   |
 static page                     free Space sleeps when idle; the first call wakes it
```

The only security change was one line. The Content-Security-Policy `connect-src` moved from
`'self'` to `'self' https://granolacowboy-gc-guide.hf.space`, and that exact string is pinned in
both `vercel.json` and the build gate so the two can never drift.
