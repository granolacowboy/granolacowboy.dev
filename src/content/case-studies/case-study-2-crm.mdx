## Context

An enterprise legal department was struggling to manage its growing volume of external counsel relationships. They relied on a legacy CRM that was heavily customized but increasingly disconnected from their modern communication and billing platforms. The legal operations team was forced to manually copy information between systems, which led to data inconsistencies and delayed vendor onboarding.

## Complication

The legacy CRM had limited API support and strict firewall rules. Any new integration had to navigate a complex set of internal security policies and pass a rigorous InfoSec review. Furthermore, the data being synchronized included sensitive contract terms and billing rates, meaning that standard middleware services like Zapier were explicitly prohibited.

## What I built

The middleware I wrote ran behind the corporate firewall. This application securely polled the legacy CRM database for changes and pushed updates to the modern billing platform using encrypted API channels. 

I wrote data-transformation scripts to map the CRM's old schema to the modern REST API. I added logging and alerting so the legal operations team saw any synchronization failure. I also built a lightweight internal web portal that allowed the team to monitor data flows and trigger manual syncs when necessary.
